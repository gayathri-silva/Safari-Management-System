 # Safari Management System

## Overview

The Safari Management System is a web-based application developed as an academic group project for managing safari trip bookings and customer operations. The system helps users browse safari packages, make reservations, manage schedules, and handle customer information efficiently.

This project was developed using Object-Oriented Programming concepts and a modular architecture to create a scalable and organized system.

---

## Features

* User authentication and authorization
* Safari trip booking management
* Customer management system
* Reservation and scheduling modules
* Database integration for storing and retrieving data
* Modular and maintainable OOP-based design
